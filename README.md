# 🗒️ Description

*Sky Factory World Generation Addon generates a full Sky Factory-style world in your Minecraft experience. Once applied, your world will be void with a customizable starter tree. You can change the starting tree and even combine this addon with others to add more trees and features.*

# ⛏️ Ore Tree Integration

*This addon is compatible with the **Ore Trees Addon**. You can use the ore-based trees directly in Sky Factory worlds. Just make sure to install the Ore Trees Addon along with this one.*

**⚠️ Warning:** If the Ore Trees Addon is not installed in your world, the ore tree options will not appear!
